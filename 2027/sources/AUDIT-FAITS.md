# Audit des faits cités dans les questions (25 septembre 2026)

Chaque fait cité dans le contexte des questions a été recontrôlé sur des sources officielles lues (INSEE, DREES, Dares, ministères, Sénat, Assemblée nationale, Conseil constitutionnel, Vie-publique.fr, Service-public.fr, Eurostat, OCDE, BCE, Commission européenne, ONU, OTAN).

Règles : un chiffre n'est affiché que s'il figure dans la source officielle citée. Les chiffres qui n'ont pas pu être confirmés ont été retirés, jamais remplacés par une estimation. Les pourcentages calculés à partir de données officielles sont signalés comme tels.
